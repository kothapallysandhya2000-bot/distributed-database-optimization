# Distributed Database Optimization

## MSc Advanced Computer Science Dissertation

This repository presents my MSc dissertation project investigating the impact of data placement strategies on storage efficiency and query performance in distributed database systems.

## Project Overview

The project investigates how data placement can be optimised in distributed database environments to improve:

- Query response time
- Data storage efficiency
- System throughput
- Resource utilisation

## Research Objectives

1. Investigate data placement strategies in distributed databases.
2. Analyse their impact on query performance.
3. Evaluate storage efficiency.
4. Explore machine learning approaches for data placement optimisation.

## Technologies

- Python
- PostgreSQL
- SQL
- Pandas
- NumPy
- Scikit-learn
- Distributed Database Systems
- Machine Learning

## Results

The research achieved approximately:

- 20% improvement in query response time
- 18% improvement in throughput
